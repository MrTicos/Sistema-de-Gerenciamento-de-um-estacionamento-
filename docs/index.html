Sistema de Estacionamento

Aplicação em C++ com interface gráfica em Qt (e menu de terminal) que controla entrada e saída de veículos, ocupação de vagas, tarifas, tickets, histórico e faturamento, com dados guardados em SQLite.

Interface gráfica

Uma janela única feita com Qt 6 (Widgets). À esquerda, o formulário do veículo com os botões de entrada e saída; à direita, as vagas livres e a tabela de veículos estacionados. Para um veículo já cadastrado, basta digitar a placa, e clicar em uma linha da tabela copia a placa para o formulário.

A janela não tem regras de negócio: ela chama a classe Estacionamento, recebe um resultado (sucesso e mensagem) e atualiza a tela.

O que o sistema faz

O atendente digita a placa; o sistema registra o horário, escolhe uma vaga compatível, calcula o valor proporcional ao tempo (em minutos) e emite o ticket. A interface gráfica cobre entrada, saída, vagas livres e veículos estacionados; as demais funções da tabela estão no menu do terminal.

Menu (terminal)FunçãoResumo
1Registrar entradaCadastra o veículo se for novo, aloca vaga e emite o ticket de entrada.
2Registrar saídaCalcula permanência e valor, libera a vaga e emite o ticket de saída.
3Consultar vagasMostra as vagas livres para carros/caminhonetes e para motos.
4Consultar veículoBusca por placa e mostra a situação atual.
5Listar veículosExibe quem está estacionado agora.
6HistóricoLista as saídas anteriores com o valor pago.
7FaturamentoSoma o valor arrecadado em uma data.
8Gerenciar veículoEdita modelo e cor, ou remove um cadastro.
9ConfiguraçõesAltera a quantidade de vagas e as tarifas.

Regras principais

Moto usa vaga de moto (exclusiva). Carro e caminhonete usam vaga de carro e pagam a mesma tarifa. Um veículo já estacionado não entra de novo e não pode ter o cadastro removido.

Conceitos de POO

Abstração
Veiculo é uma classe abstrata: define o que todo veículo faz sem fixar como a tarifa é calculada.
Herança
Carro, Moto e Caminhonete herdam de Veiculo.
Polimorfismo
O método virtual puro calcularTarifa é implementado por cada classe derivada; o comportamento é escolhido pelo objeto concreto em tempo de execução.
Encapsulamento e modificadores de acesso
Estado interno private ou protected, acessado por métodos public.
Separação de responsabilidades
JanelaPrincipal (que herda de QMainWindow) só exibe e coleta dados; as regras ficam em Estacionamento e o acesso ao SQLite, em Banco.
Referências e ponteiros
Estacionamento usa uma referência para Banco; Banco guarda o ponteiro para a conexão SQLite.

    }

Banco de dados e CRUD

Todo o acesso ao SQLite passa pela classe Banco. As tabelas são criadas na primeira execução.

OperaçãoOnde acontece
CreateCadastro de veículo e registro de entrada

Como executar

Requisitos: compilador C++17, CMake 3.20 ou superior, SQLite3 e, para a interface gráfica, Qt 6 (Widgets). Sem o Qt 6, o CMake compila só a versão de terminal.

Linux 
sudo apt install build-essential cmake libsqlite3-dev qt6-base-dev
cmake -S . -B build
cmake --build build
./build/estacionamento        # terminal
./build/estacionamento_gui    # interface gráfica
Windows (MSYS2 / MinGW) 
pacman -S mingw-w64-ucrt-x86_64-qt6-base
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH="C:/msys64/ucrt64"
cmake --build build
.\build\estacionamento.exe        # terminal
.\build\estacionamento_gui.exe    # interface gráfica
